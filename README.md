# Shezmusic — Interactive Web Music Player

A responsive browser-based music player built with HTML, CSS, and JavaScript featuring custom playlists, album artwork, and interactive audio playback controls.

## Features
- **Audio Controls:** Play, pause, skip tracks, and scrub through songs via an interactive progress bar.
- **Playlist & Artwork:** Dynamically loads track metadata and album covers.
- **Responsive Design:** Styled with CSS3 for desktop and mobile browsers.
